## Summary

The previous vector-measure probe left "the infinite countably additive
extension" of the norm-prescribed problem open, and asserted (in one bullet)
that any finite-semivariation vector measure is excluded for `p notin [0,1]`.
Both need correction:

1. **The extension exists, in infinite-dimensional value spaces, by a standard
   construction.** For `p` with `|p|^alpha + |1-p|^alpha = 1` (`alpha` finite),
   the indicator map `mu(E) = 1_E` into `L^alpha(P_r)`, `r = |p|^alpha`, is a
   countably additive vector measure on the **full** history sigma-algebra with
   `||mu(cyl C)||_alpha = |A_p(C)|` on every cylinder — in particular on the
   doubly-principal restriction. Flagship: `p = (1+i)/2`, `alpha = 2`,
   `r = 1/2` (Theorem B). This is a known folklore construction applied here,
   not a new technique (see Prior art).
2. **The extension is impossible in finite-dimensional value spaces** — the
   prior report's Theorem 1, whose finite-dimensional qualifier is essential.
   Its unqualified "finite-semivariation ... excluded" bullet is refuted by the
   same construction: the indicator measure has **finite** semivariation
   (`P_r(E)^{1/alpha}`) and **infinite** total variation (Theorems A/D).
3. **Exact existence locus for this construction** (Theorem C): `p` works with
   some finite `alpha` iff `p` lies in
   `{0,1} union {|p| < 1, |1-p| < 1}`; real `(0,1)` admits only `alpha = 1`; non-real lens
   points admit exactly one `alpha* in (1, infty)`, equal to `2` exactly on the
   open Thales circle; `p in {0,1}` admit every `alpha` (degenerate); lens
   boundary and exterior admit none.

## Setting

Two concrete instances of one abstract setting are used; both have cylinders
with a two-parameter measure law `P_r(cyl C) = r^{L(C)} (1-r)^{h(C)}` and
amplitudes `A_p(C) = p^{L(C)} (1-p)^{h(C)}`:

- **Binary model** (computational witness): `Omega = {0,1}^N`,
  `Sigma` = product sigma-algebra, cylinders of finite words, `L` = number of
  ones, `h` = number of zeros, `P_r` = Bernoulli(`r`) product measure.
- **Causet model** (the project's setting, following
  `research/creative/RESULT.md`): `Omega` = locally finite naturally labelled
  causal sets on `N`; cylinders `cyl C` of finite labelled orders `C`;
  `L(C)` = covers, `h(C) = binom(|C|,2) - R(C)` = incomparable pairs; `P_r` =
  classical transitive percolation with edge probability `r`. The cylinder law
  `P_r(cyl C) = r^{L(C)}(1-r)^{h(C)}` is the standard transitive-percolation
  formula, used (audited) in RESULT.md's real-probability interpretation; this
  task re-verified it **exactly** (Fraction arithmetic, edge-subset
  enumeration) for all labelled orders with 3 and 4 labels (7 and 40 orders) at
  `r in {1/2, 2/5}` — see Verification, check 5.

`\widetilde R_p` denotes the sigma-algebra generated by doubly-principal
cylinders (RESULT.md). The scalar no-go (countably additive finite complex
measure agreeing with `A_p` on every doubly-principal cylinder iff
`p in [0,1]`) is the project's audited theorem draft; the all-level two-cap
bound `V_{k+2}(p) >= |p|(|p|+|1-p|)^k c_s` with
`c_s = prod_j (1-s^j) > 0`, `s = |1-p|/(|p|+|1-p|)`, is used below **as a
project-audited black box** (not re-proved here; finite levels `V_4, V_5`
re-verified numerically).

## Theorem A — the indicator measure (abstract; proved here in full)

Let `(Omega, Sigma, P)` be a **finite** measure space and `1 <= q < inf`.
Define `mu: Sigma -> L^q(P)` by `mu(E) = 1_E`. Then:

**(a) Countable additivity.** For pairwise disjoint `(E_n)`, with
`U = biguplus E_n` and `U_N = biguplus_{n<=N} E_n`:

`||mu(U) - sum_{n<=N} mu(E_n)||_q = ||1_{U setminus U_N}||_q = P(U setminus U_N)^{1/q} -> 0`,

by continuity from above of the finite measure `P` (finite total measure is
used exactly here). The tail bound depends only on the measure of the
remaining subfamily, so the series converges **unconditionally**:
`mu(biguplus E_n) = sum_n mu(E_n)` in `L^q`.

**(b) Norm.** `||mu(E)||_q = P(E)^{1/q}`.

**(c) Semivariation (dual form) is finite everywhere.** For
`g in L^{q'}` (`1/q + 1/q' = 1`), the scalar retract is
`(g o mu)(A) = int_A g dP`, with total variation `|g o mu|(E) = int_E |g| dP`.
Hölder with `1_E` gives `int_E |g| <= ||g||_{q'} ||1_E||_q = ||g||_{q'} P(E)^{1/q}`,
so `|mu|(E) := sup_{||g||_{q'} <= 1} |g o mu|(E) <= P(E)^{1/q}`, attained at
`g = P(E)^{-1/q'} 1_E` (norm 1, value `P(E)^{1/q}`; trivial if `P(E)=0`).
So `|mu|(E) = P(E)^{1/q}`. The partition form (sup over finite disjoint
families and coefficients `|alpha_i|<=1` of `||sum alpha_i mu(E_i)||_q`) gives the same value `P(E)^{1/q}`, attained
by the single-piece family.

**(d) Total variation.** If `q > 1` and `P` is nonatomic, then for every `E`
with `P(E) > 0`, `|mu|_{var}(E) = sup sum_i P(E_i)^{1/q} = infty`: by
nonatomicity split `E` into `N` pieces of measure `>= P(E)/N` each (standard
splitting lemma, induction on `N`), giving
`sum_i ||mu(E_i)||_q >= N^{1-1/q} P(E)^{1/q} -> infty`. If `q = 1`,
`|mu|_{var}(E) = P(E)`: the vector measure has classical probability norms
and variation; it remains an indicator-valued measure, not literally scalar.

This is elementary and should be read as folklore; it is written out because
the task requires the proof on the stated domain. The `q = infty` case is
**excluded**: `E ↦ 1_E` into `L^infty` fails countable additivity when there are infinitely many disjoint
positive-probability sets (`||1_{uplus E_n} - sum_{n<=N} 1_{E_n}||_infty = 1`).
On a finite atomic space the L-infinity indicator measure can be countably additive;
nonempty null sets do not give this obstruction. The L^infinity version is exactly the finitely-additive
folklore example stated in MathOverflow 25141 (2010).

## Theorem B — norm-prescribed counterexample on the full sigma-algebra and on `\widetilde R_p`

Let `q in [1, infty)`, `p in C` with

`|p|^q + |1-p|^q = 1`, and `r := |p|^q in [0,1]`.

In either instance of the Setting, `mu(E) = 1_E in L^q(P_r)` is a countably
additive `L^q(P_r)`-valued measure on the **full** history sigma-algebra with

`||mu(cyl C)||_q = P_r(cyl C)^{1/q} = r^{L(C)/q} (1-r)^{h(C)/q} = |p|^{L(C)} |1-p|^{h(C)} = |A_p(C)|`

for every cylinder `C`. Restriction to any sub-sigma-algebra — in particular
`\widetilde R_p` — preserves countable additivity and values of cylinders in the restricted domain, and
the semivariation stays finite (`<= P_r(E)^{1/q}` by Theorem A(c)).
For nonclassical parameters satisfying the locus equation, total variation
on the DP restriction is infinite on Omega by its divergent disjoint level
families. The stronger assertion about every non-null set after restriction
is not established here; nonatomicity of the full measure alone would not
justify it for an arbitrary sub-sigma-algebra.

**Flagship.** `p = (1+i)/2` (nonreal): `|p|^2 + |1-p|^2 = 1/2 + 1/2 = 1`, so
`q = 2`, `r = 1/2`. There is a countably additive `L^2(P_{1/2})`-valued
measure on the full labelled-history sigma-algebra — hence on `\widetilde
R_p` — with `||mu(cyl C)||_2 = |A_{(1+i)/2}(C)|` for **every** cylinder, a
strictly stronger prescription than the doubly-principal-only one asked by the
previous probe. Its semivariation is `P_{1/2}(E)^{1/2}` (e.g. `1` on `Omega`);
its total variation on `Omega` is infinite.

**Endpoints.** `p in {0,1}`: `r in {0,1}`, `P_r` is the point mass on the
all-zeros (all-ones) history (binary) resp. the antichain (chain) history
(causet), `L^q(P_r) ~= C` via `f ↦ f(omega_*)`, and `mu(E) = delta(E)` is the
Dirac measure; the prescription holds (`|A_0(cyl C)| = 1` iff `C` has no
ones/no covers iff `omega_0 in cyl C`). Valid but degenerate; nothing
quantum. These are the locus-theorem points admitting **every** `alpha`.

**Known-construction disclosure.** Theorem A+B is a standard folklore
construction (indicator map into `L^q`) applied to this project's cylinder
law. No mathematical novelty is claimed for the construction; the
project-specific step is the reparametrization `r = |p|^q` under the locus
equation, which is an elementary lemma (below).

## Theorem C — exact existence locus for this construction

Write `u = |p|`, `v = |1-p|`, `S(alpha) = u^alpha + v^alpha`. There is a
finite `alpha >= 1` with `S(alpha) = 1` **iff `p` lies in
`L union {0,1}`, where `L = B(0,1) cap B(1,1)`**. Exactly:

1. `p in {0, 1}`: `S(alpha) = 1` for **every** `alpha in [1, infty)` (the
   construction degenerates to a Dirac measure; every `alpha` works).
2. `p in (0,1)` real: **exactly `alpha = 1`** (`u, v in (0,1)` make `S` strictly
   decreasing; `S(1) = u + v = 1`; so `S(alpha) < 1` for `alpha > 1`). Then
   `r = p` and `||mu(cyl C)||_1 = P_p(cyl C) = A_p(C)`: the classical case,
   no new content.
3. `p in L` nonreal: `u, v in (0,1)`, `S` is strictly decreasing on
   `[1, infty)`, `S(1) = u + v > 1` (strict triangle inequality, equality iff
   `p in [0,1]`), and `S(alpha) -> 0`. Hence **exactly one**
   `alpha*(p) in (1, infty)` with `S(alpha*(p)) = 1`, and:
   - `alpha*(p) = 2` iff `u^2 + v^2 = 1` (the open Thales circle
     `|p - 1/2| = 1/2 setminus {0,1}`);
   - `alpha*(p) in (1,2)` iff `|p - 1/2| < 1/2`; `alpha*(p) in (2, infty)`
     iff `p` is in the lens but outside the circle.
   Then `r = u^{alpha*} in (0,1)` and `1 - r = v^{alpha*}` automatically.
4. `p` on the lens boundary or outside (i.e. `max(u,v) >= 1`, `p notin [0,1]`):
   **no solution**. If `u = 1 > v`: `S(alpha) = 1 + v^alpha > 1` for all
   finite `alpha` (similarly `v = 1 > u`; if `u = v = 1`,
   `p = 1/2 ± i sqrt(3)/2` and `S = 2`). If `max(u,v) > 1`:
   `S(alpha) >= max(u,v)^alpha >= max(u,v) > 1` for `alpha >= 1`.

*Remarks.* (i) The `alpha = 2` level set is the Thales circle without its
endpoints; the endpoints belong to **every** level set. (ii) Each
`alpha in (1, infty)` level set is a closed curve through 0 and 1, nonreal away from those endpoints, symmetric under
`p ↦ conj(p)` and `p ↦ 1 - conj(p)`; the curves with endpoints removed are nested (strict decrease of
`S`) and exhaust `L setminus [0,1]`. (iii) `alpha*` has **no unique limit at
the endpoints**: along the open segment the admitted value is `1`, along the
open circle it is `2`, and at `p in {0,1}` every value is admitted.
(iv) No closed form for `alpha*` in general; when `u = v` (i.e. `Re p = 1/2`),
`alpha* = ln(1/2)/ln u`, e.g. `p = 1/2 + 0.55 i` gives `alpha* ≈ 2.336575`.

*Proof.* Case 2 and case 3 are the monotonicity/IVT argument above; case 1 is
direct; case 4 is the two sub-arguments displayed. Strictness of the triangle
inequality: `|p| + |1-p| = 1` iff `p` and `1-p` are nonnegative reals with a
common argument, i.e. `p in [0,1]`. ∎

**Scope.** Theorem C classifies only for which `p` **this particular
`L^alpha(P_{|p|^alpha})` indicator construction** realizes the prescription.
It does not classify vector measures in general: other infinite-dimensional
value spaces, other norms, or value-prescribing (phase-carrying) measures are
untouched.

## Theorem D — finite-dimensional no-go (sharp form of the prior Theorem 1)

Let `X` be a **finite-dimensional** Banach space and `mu: Sigma_full -> X`
countably additive with `||mu(cyl C)|| = |A_p(C)|` on every doubly-principal
cylinder (causet model). Then `p in [0,1]`.

*Proof.* (1) Fix a basis and coordinate functionals `x*_1, ..., x*_d` with
`||x|| <= c sum_j |x*_j(x)|`. Each `x*_j o mu` is a countably additive scalar
measure, hence has finite total variation (standard; a countably additive real
or complex measure has finite variation on all of `Sigma`). Then every finite
partition satisfies `sum_i ||mu(E_i)|| <= c sum_j |x*_j o mu|(Omega) < infty`:
`mu` has finite total variation. (2) For each `k`, the doubly-principal
cylinders of level `k+2` are pairwise disjoint, so together with the
complement of their union they form a finite partition; thus
`|mu|_{var}(Omega) >= V_{k+2}(p)`. (3) The project-audited two-cap bound gives
`V_{k+2}(p) >= |p|(|p|+|1-p|)^k c_s -> infty` for `p notin [0,1]`
(`t = |p| + |1-p| > 1`). Contradiction. ∎

**Self-contained binary analogue (Corollary D.1).** In the binary model, if
`||mu(cyl w)|| = |A_p(w)|` on all level-`k` words, then
`sum_{|w|=k} ||mu(cyl w)|| = sum_w |p|^{L(w)}|1-p|^{h(w)} = (|p|+|1-p|)^k`,
which diverges for `p notin [0,1]`; the same three-step argument excludes any
finite-dimensional countably additive solution. (No two-cap bound needed.)

**Corollary D.2.** The finite-level `R^2` polygon families of the previous
probe admit **no** countably additive extension in any finite-dimensional
space, on either model. The `L^q` counterexample of Theorem B necessarily
lives in an infinite-dimensional value space. In the binary model its level-`N` values
span a `2^N`-dimensional subspace. For causets the number is the number of
naturally labelled N-orders with positive classical cylinder probabilities.

## Theorem E — fixed direction

If `mu: Sigma -> X` is countably additive (a complex Banach `X`) with
`mu(cyl C) = A_p(C) v` on the prescribed cylinders for a fixed `v != 0`,
then `p in [0,1]`. Write `f=x* o mu` for the scalar measure in the proof.
*Proof.* Choose `x* in X*` with `x*(v) = 1`; then `x* o mu = f` is a countably
additive scalar measure with finite variation, and the same level-sum
divergence (`V_{k+2}(p)`, resp. `(|p|+|1-p|)^k` in the binary model) forces
`p in [0,1]`. ∎ So the scalar no-go extends to **all** fixed-direction vector
lifts; the norm-prescribed construction evades it precisely by letting
directions vary (its directions encode set membership, not the phase of
`A_p`).

## Separations requested by the brief

- **Semivariation vs total variation.** `mu` (Theorem B) has finite
  semivariation on every set (`P_r(E)^{1/q}`; equal to `1` on `Omega` for the
  flagship) and infinite total variation on Omega at nonclassical parameters. This is a
  concrete counterexample to the prior report's unqualified bullet "any
  bounded-variation or finite-semivariation vector measure is excluded", and
  it shows the finite-dimensional qualifier in that report's Theorem 1 is
  essential. It is also not an accident: by the classical Bartle–Dunford–
  Schwartz theory a countably additive vector measure on a sigma-algebra has
  bounded range (BDS 1955, cited here at discovery depth only), so finite
  semivariation was never the obstruction — finite **variation**, forced by
  finite dimension, was.
- **Finite vs infinite dimensions.** Same algebra, same prescription:
  impossible in every finite dimension (Theorem D), solved in
  `L^q(P_{|p|^q})`, `q > 1` (Theorem B). This particular comparison changes the value space;
  the later coordinator classifications also distinguish target event families.
- **Why the finite `R^2` polygons do not establish infinite extension.**
  (a) They cannot be extended in `R^2` at all (Corollary D.2). (b) Their
  existence per level is equivalent to the polygon inequality at each node —
  a statement about **finite** additivity only; countable additivity fails to
  transfer because the level norm sums `(sum over a level of ||mu||)` diverge,
  which is exactly what a compactness/martingale argument would have to
  control. (c) The actual infinite solution re-enters through an
  infinite-dimensional value space whose per-level dimension is unbounded
  (`2^N` at level `N` in the binary witness), so no fixed-dimension limiting
  argument produces it.
  The finite witness ruled out finite-level obstructions — necessary, far from
  sufficient.

## Strongest contrary evidence (against the interest of this task's claims)

- **Genericity objection (strongest).** The prescription
  `||mu(cyl C)|| = |A_p(C)|` is satisfied for a *generic* reason: any finite
  measure space yields an indicator measure, and the locus equation merely
  reparametrizes `r`. A referee can therefore view Theorem B as a

  trivial rather than deep. This objection is adopted here as the verdict:
  folklore-grade construction, no depth claimed.
