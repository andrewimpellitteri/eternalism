# Covariant observer access to the phase-aligned event: a finite comparison

Sole-worker result, 2026-10-21. This is a finite algebraic comparison, not a
physical observer model and not a causal-set dynamics theorem.

## Two observer algebras

Fix a stage `n` of a finite history space with labelled causets `C` and
amplitudes `A(C)`. A history observable is a function on the labelled
histories; an observer algebra is a unital `*`-subalgebra of the diagonal
algebra, or equivalently the algebra of projectors onto the sets it can
resolve.

1. **Cardinality-only algebra `A_card`.** The only resolved event is the stage
   itself (and its complement at that stage). At a fixed `n` it contains
   `empty` and the full level. It cannot resolve a proper subset of the level.
2. **Unlabelled-causet algebra `A_iso`.** Generated by isomorphism classes
   `[C]` of labelled causets. A function is measurable iff it is constant on
   each class. The class-pinching channel
   `P_obs(rho) = sum_[C] Pi_[C] rho Pi_[C]`
   is covariant under relabelling because permutations preserve classes. Its
   adjoint image is the block-diagonal algebra of class projectors.

For a register model with basis `|w>`, the analogous quotient is by
permutations of the register positions; the orbits are the word-count classes.

## The phase-aligned event

For complex percolation at `p=(1+i)/2`, `A_p(C)=p^L q^h` has phase
`(L-h) pi/4`, where `L` is the number of covers and `h` the number of
incomparable pairs. Both are isomorphism invariants, so the phase is constant
on `A_iso` classes. Define

```
E = { C : (L(C)-h(C)) mod 8 in {0,1} }.
```

For the symmetric binary register `(q|0>+p|1>)^{tensor n}`, the amplitude
`a_w=p^k q^{n-k}` has phase `(2k-n) pi/4`, and `k` is constant on permutation
orbits. The analogous ray event is therefore also class-measurable.

## Result

- **Cardinality-only observer:** `E` is a proper subset of the level for every
  tested `n`, so its projector is not in `A_card`. The target effect is outside
  the adjoint image. Proof: a projector in `A_card` is a scalar on the whole
  level; `E` is not.
- **Unlabelled-class observer:** `E` is a union of classes, hence in `A_iso`
  and in the adjoint image of the class-pinching channel. The phase-aligned
  event **survives quotienting birth labels** in these symmetric models.
- **Discarding inaccessible records:** dephasing within a class does not
  remove the class-level phase, because the phase is a class invariant. A
  channel that retains only the cardinality does remove it. The distinction is
  the algebra, not the record count.

## Finite scaling

The selected class sum `S_n = sum_{[C] in E} N([C]) A_p(C)` grows in the tested
range (exact Gaussian rationals):

| `n` | selected classes | `|S_n|^2` |
|---:|---:|---:|
| 2 | 1 | 1/2 |
| 3 | 2 | 1/2 |
| 4 | 5 | 205/64 |
| 5 | 16 | 461/32 |
| 6 | 85 | 4938221/32768 |

The binary register shows the same qualitative growth: `|S_n|^2 = 9/4, 25/4,
81/4, 1089/4, 263169/4` at `n=4,6,8,12,20`. This is finite evidence, not a
proof that the class event has divergent variation. A kill criterion is
therefore explicit: if the class sum is bounded (or the phase is not
class-invariant), the unstable witness does not survive the quotient.

## Mathematical versus physical access

`A_iso` is a mathematical quotient. It is not derived from a causal-set
observer, a local region, or a physical instrument. The result says that a
*class-resolving* observer can address the event in these models, while a
*cardinality-only* observer cannot. It does not say that a cosmological
observer has access to the class label, the phase, or the coherent erasure
required to measure the event.
