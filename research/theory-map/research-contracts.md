# Candidate research contracts (testable mathematical content)

Status: worker submission for review, 2026-10-19. Five candidate contracts
satisfying the brief's "at least three with testable mathematical content".
Each follows the claim-contract structure of `knowledge/NOVELTY.md` (exact
question; predecessors; delta; smallest example; falsifiers; novelty-kind
separation). **None is vetted: no novelty audit has run, none may be called
open, novel, or true.** All are submissions to the `novelty-audit` task and,
if selected, to the `baseline-reproduction` task. Where a contract cites
theorem hypotheses, they are the hypotheses recorded in the cited sources at
their recorded read depth; re-extraction from the pinned source precedes any
implementation (several falsifiers are exactly "an existing theorem already
does this").

Shared verification policy (from `knowledge/methods/handoff-contract.md`,
`meth-sw-lean-2026`, `meth-diagrammatica-2026`): freeze source versions;
provenance sweep; oracle checks with anchors; adversarial pass; Lean (or
Isabelle) only after correspondence audit; `#print axioms` / dependency
closure on any Lean artifact; finite countermodels always state their domain
bound and never count as general theorems.

## RC-1 — Classification: interaction-dependent clocks supporting autonomous isometric relational dynamics

- **Exact question.** For a constraint `C = H_C + H_S + H_int ≈ 0` and a
  covariant clock instrument `{E_t}`, characterize when there exist reduction
  maps `R_q : H_phys → K` (q a clock coordinate) onto a **common** image
  `K`, injective on a declared common domain `D ⊆ H_phys`, such that
  `U_eff(q2, q1) := R_{q2} (R_{q1}|_D)^{-1}` is (i) well defined on `K`,
  (ii) an isometry for the physical inner product, and (iii) generated by a
  single time-independent self-adjoint `H_eff` — rather than being a
  parameter-dependent relabeling or a memory-kernel evolution. Deliverables:
  either a necessity/sufficiency theorem for a sharply stated class, or a
  counterexample family inside a natural class where autonomy or isometry
  fails.
- **Predecessors and assumption/result comparison:**
  1. Smith–Ahmadi (`frontier-smith-ahmadi-interacting-2019`, full-text;
     arXiv:1712.00081v3): assumes tensor split, self-adjoint `H_int`,
     chosen time-independent physical inner product; result: conditional
     Schrödinger equation with kernel `K(t,t') = <t|H_int|t'>` and norm
     constancy. Does not give Dirac/Heisenberg counterparts, hence no
     classification.
  2. Relational trinity (`frontier-relational-trinity-2019v3`, full-text):
     assumes **no interaction** and nondegenerate clock spectra for the
     continuous theorems; result: three-picture equivalence. Its own
     conclusion flags interactions as open for generic models.
  3. QRFs beyond subsystems (`frontier-qrf-beyond-subsystems-2026`,
     full-text): finite dimensions + compact Lie group; result: for the
     specific model `C = P1 + P2 + K(X1 − X2)^2` the non-local COM frame
     decouples relative dynamics; explicitly no all-interactions claim.
     Its App. B.1 kernel `K(t,t') = (<t|⊗1) H_int (|t'>⊗1)` is the exact
     object RC-1 must generalize.
- **Delta:** predecessors each give one sufficient instance or one restricted
  theorem; no recorded source states necessary and sufficient conditions.
  The question is therefore *posed*, not known to be open — falsifier below
  governs.
- **Smallest reproducible example (first bounded test).** The finite Abelian
  model of the 2026 preprint: `C = P1 + P2 + K(X1 − X2)^2`, `K ∈ Z_n`,
  physical states `|d; K d^2>`. Compute explicitly: (a) the COM-frame
  reduction and its induced dynamics; (b) `U_eff` for the first-particle
  frame (where the paper reports no autonomous generator) and verify it
  fails isometry/autonomy; (c) then replace the potential by a one-parameter
  family `V_λ(X1 − X2)` and locate numerically (exact finite arithmetic)
  where decoupling survives. n up to a few hundred is exact integer
  arithmetic; no floating-point claims.
- **Falsifiers (novelty-defeating searches, to run BEFORE implementation):**
  (i) an existing necessary/sufficient condition in the interaction-PW,
  periodic-clock (`map-periodic-clock-trinity-2026v3`), Mendes
  (`map-pw-quasi-ideal-2021v1`), or algebraic/instrument QRF literature;
  (ii) proof that the classification reduces to a known representation
  change with identical accessible probabilities (then the "classification"
  is physically empty and must be labeled as such); (iii) the 2026 paper's
  own sequel work (forward citations unchecked — a recorded project gap).
- **Novelty separation:** mathematical = the classification theorem or
  counterexample family; formalization = Lean statement of the finite case
  with audited correspondence; physical = none unless a class boundary maps
  to an instrument-accessible difference (must be argued, not assumed);
  philosophical = none by itself; clock choice ≠ passage.
- **Testable mathematical content:** explicit matrices over `Z_n`; isometry
  predicate; trace/inner-product identities; finite-domain exhaustive check
  with stated bound.

## RC-2 — Premise-dependency classification for definable definiteness and simultaneity relations

- **Exact question.** Over time-oriented Minkowski `(M, kappa, orientation)`
  with a distinguished observer worldline (per node family N02/N04), classify
  which premise sets force (a) `R` = causal past (Stein-type definiteness),
  (b) simultaneity = Einstein synchrony (Malament-type), (c) neither (a
  countermodel family). Deliverables: (1) a proof of the context-preserving
  Stein characterization — invariant + reflexive + transitive + contains the
  full causal past + unsettled condition ⇒ `R` = causal past — with each
  premise's necessity shown by explicit countermodel; (2) an
  assumption-dependency table for (a) vs (b) showing the premises are
  non-interchangeable (X16's non-transfer claim as a theorem-shaped
  statement).
- **Predecessors:**
  1. Malament 1977 via `found-sarkar-stachel-1999` (full-text) and
     `found-sep-malament` (full-text secondary; primary
     `found-malament-1977` still abstract-depth — must be obtained first):
     uniqueness of Einstein synchrony under definability + invariance +
     temporal-reflection premises; null-cone alternatives when
     temporal-reflection is dropped.
  2. Stein 1991 (`found-stein-1991`, full-text; audited reconstruction in
     `knowledge/foundations/audit.md`): causal-past characterization under
     contextual premises (i)–(iv); the OCR'd isolated statement is false —
     two countermodels already constructed in
     `knowledge/checks/correspondence-cases.jsonl` (cases 1–2).
  3. Besnard (`seed-besnard-simultaneity`, abstract) and Andréka et al.
     (`seed-axiomatic-relativity`, abstract): definability-vs-coordinate
     freedom and first-order axiomatizations — hypotheses unextracted;
     reading them is part of the falsifier duty.
- **Delta:** the audit already produced the reconstruction and two ablation
  countermodels; no recorded source gives a systematic necessity table for
  the Stein premises or a formal non-interchangeability statement. Both
  may exist in the axiomatic-relativity literature — falsifier (iii).
- **Smallest reproducible example.** Formalize the five premises over a
  finite (n ≤ 6-point) causal set or first-order Minkowski fragment; verify
  each of the two known countermodels by enumeration; produce a
  machine-checked certificate for the characterization over the chosen
  fragment. The finite result is finite-domain only and will be labeled so.
- **Falsifiers:** (i) Besnard or the axiomatic-relativity literature already
  states the necessity table (likely candidates — must be read at full text
  first); (ii) the characterization is an immediate corollary of
  Malament-style definability lemmas; (iii) an existing Isabelle/Lean
  formalization of Stein's argument exists (the Schutz and Stannett–Németi
  bases, `form-*` records, show the infrastructure pattern but no recorded
  Stein formalization).
- **Novelty separation:** mathematical = necessity/countermodel table;
  formalization = first verified Stein/Malament premise dependency in this
  project (reusable missing foundation, valuable even if mathematically
  easy); physical = none; philosophical = sharpens D02/D03 by naming which
  premise does the work.
- **Testable mathematical content:** first-order premises; explicit
  countermodel witnesses; enumeration certificates; Lean-checkable finite
  statement.

## RC-3 — Normalization and interference for frequency-sector-coherent conditioning

- **Exact question.** In the relativistic trinity model (N12: `C_H = s
  p_t^2/2 + H_S ≈ 0`, sectors `σ = ±`), determine which clock preparations
  and conditioning instruments yield normalized conditional probabilities
  for **sector-coherent** clock superpositions, and whether any normalized
  sector-coherent conditioning is operationally distinguishable from a
  probabilistic sector mixture under the paper's clock POVM effects.
  Deliverables: either (a) an explicit normalized conditioning rule with a
  derived cross-sector interference term and its measurability conditions,
  or (b) a no-go result: no normalized conditioning on time+frequency yields
  sector-coherent probabilities without an external phase reference.
- **Predecessors:**
  1. `frontier-relativistic-trinity-2020v1` (full-text): sectorwise
     equivalence; Sec. VI warns mixing sectors can spoil
     normalization/probability (factor 1/2 sector normalization recorded);
     no sector-coherent conditioning rule given.
  2. `frontier-relational-trinity-2019v3` (full-text): covariant POVM
     conditioning machinery the rule must respect.
  3. `frontier-spacetime-qrf-2021` (abstract): superpositions of proper
     times — the nearest treatment of coherent clock-parameter branches;
     must be read at full text before any gap claim (X07's falsifier).
- **Delta:** no recorded source states a sector-coherent normalized rule or
  the no-go; Sec. VI's warning is recorded at full-text depth but its
  positive boundary is unexplored in the lanes. Claim status: **posed
  question with a recorded caution**, not an open-problem assertion.
- **Smallest reproducible example.** A two-sector finite-dimensional toy:
  Hilbert space `C^2 ⊗ C^n` with constraint diagonal in a `σ = ±` clock
  parameter; implement the paper's sector states (Eqs. 25–29 transcribed
  from the pinned source first); compute conditional states for (i) sector
  eigenstate clocks, (ii) coherent `(|+> + |−>)/√2` clock states, for the
  three candidate conditionings: sector-mixed ratio, sector-projected, and
  POVM-effect Bayes conditioning; compare normalized probabilities and
  exhibit (or bound) the interference term. Pure finite linear algebra.
- **Falsifiers:** (i) N13's updated PW conditional probabilities already
  solve the normalization problem generally (abstract-level lead — must be
  read); (ii) a QRF paper treats sector coherence explicitly; (iii) proof
  that the toy's interference term is unobservable under all clock-POVM
  effects, reducing the question to the recorded Sec. VI caution.
- **Novelty separation:** mathematical = rule or no-go in the stated model;
  physical = an interference measurability condition (observable content
  only if an instrument realization is argued); formalization = finite toy
  certificate; philosophical = none — sector bookkeeping is descriptive.
- **Testable mathematical content:** explicit conditional-probability
  formulas; positivity/normalization inequalities; a computable interference
  coefficient.

## RC-4 — Record-observable distinguishability of growth histories within a covariance class

- **Exact question.** For classical sequential growth dynamics (N08) with
  fixed covariance parameters, call two growth histories record-equivalent
  if every bounded internal record observable (labeled-poset invariants
  accessible to embedded observers, with an explicit access bound) has the
  same distribution. Determine: (a) whether record-equivalence coincides
  with equality of the final (unlabeled) poset's distribution — the
  "growing vs completed history" boundary inside this family (NOVELTY
  candidate A, strictly bounded); (b) an invariant separating inequivalent
  histories if (a) fails. Deliverables: a theorem for the bounded family
  with the access bound stated, plus a finite enumeration script and, for
  any invariant proposed, its explicit computation.
- **Predecessors:**
  1. `frontier-causal-growth-1999` (abstract): growth model, covariance
     conditions; full transition rules to be extracted from the pinned
     paper before any run (currently abstract-depth — the extraction step is
     mandatory and is the contract's first task).
  2. `frontier-causal-becoming-2015` (abstract): interpretive analysis;
     guards the bridge-premise separation (growth ≠ passage).
  3. `frontier-causal-embedding-2026` (abstract): embedding uniqueness; X20
     orthogonality must be checked so the contract does not collide with
     (or duplicate) rigidity results.
- **Delta:** the distinguishability question with explicit record access
  bounds is not stated in any recorded source; causal-set "observable"
  literature exists and must be searched (falsifier (i)).
- **Smallest reproducible example.** n ≤ 6: enumerate all linear extensions
  and covariance-class growth sequences; compute record-observable
  distributions for access bounds 1 and 2; exhibit two histories with the
  same final poset but different record statistics (or prove equality for
  the bounded family by exhaustive check with stated bound).
- **Falsifiers:** (i) known results on labeling ensembles / observables in
  causal sets already characterize this distinguishability; (ii) the access
  bound chosen is equivalent to full labeling knowledge (making (a) trivial
  by construction); (iii) covariance-class equivalence is already known to
  imply record-equivalence for these observables (then the contract's output
  is a corollary and must be labeled as such).
- **Novelty separation:** mathematical = bounded equivalence theorem or
  separating invariant; physical = none (model-internal); formalization =
  enumeration certificates, optional Lean check of the finite statement;
  philosophical = D07 sharpened: any "growth = becoming" reading inherits
  exactly the (non-)distinguishability proved — within the stated family
  only.
- **Testable mathematical content:** transition probabilities (explicit
  rational numbers); distributional equality predicates; exhaustive finite
  enumeration with stated domain.

## RC-5 — Separating the four memory criteria for clock-conditioned dynamics

- **Exact question.** Construct a minimal clock+system model in which
  homogeneous-semigroup failure, CP-indivisibility, information backflow,
  and multi-time process memory come apart, then use it to state precisely
  which criterion the N15 proposal's Eq. (10) establishes (after extracting
  its derivation). Deliverables: the separating model with explicit maps and
  computations, plus a criterion-classification table for N15's claims.
- **Predecessors:**
  1. `knowledge/checks/correspondence-cases.jsonl` case 5 (project checks;
     Luna-reviewed): Gaussian dephasing `exp(-t^2/2)` — CP-divisible, not a
     homogeneous semigroup. Starting point, not clock-conditioned.
  2. Chruściński dynamical-map review (`knowledge/COORDINATOR_REVIEW.md`
     lead; arXiv:2209.14902, abstract-level only — must be read) and
     Nestmann–Bruch–Wegewijs (arXiv:2002.07232, abstract-level): distinct
     memory criteria and local-generator/kernel relationships.
  3. `frontier-page-wootters-measurements-2023` (full-text): nonunitary,
     time-nonlocal conditioned dynamics for nonideal clocks — supplies the
     clock-conditioned map family.
- **Delta:** no recorded source separates the four criteria *for
  clock-conditioned maps*; the coordinator's audit questions (D08) state the
  need. Abstract-level predecessors must be read first; if one already
  separates them generally, the contract collapses to applying it to N15 —
  which is still a valid audit output, labeled non-novel.
- **Smallest reproducible example.** Extend case 5: a two-level system
  conditioned on a finite qubit clock (N10's example 3 class), with the
  clock-triggered channel family `Φ_t`; compute the four criteria exactly
  (finite dimensions; CP-divisibility via the known qubit-channel
  criteria — cited from the read review, not from memory); exhibit a
  parameter point where the criteria disagree in both directions.
- **Falsifiers:** (i) an existing general separation theorem (then apply,
  don't claim); (ii) N15's full text shows its claim already matches one
  precise criterion (audit resolves D08 without new math — a successful
  *audit* outcome, not a novelty claim); (iii) the four criteria provably
  coincide for the entire clock-conditioned family (then the separating
  model is impossible and D08's answer is "they agree here" — also
  publishable as an audit note).
- **Novelty separation:** mathematical = the separating family (if new);
  physical = none (model-internal); formalization = exact finite
  computations with anchors; philosophical = none; explicitly **not** a
  claim about thermodynamic arrows (project standard).
- **Testable mathematical content:** channel compositions; divisibility
  predicates; explicit parameter inequalities; anchored numerics.
