## Scope and limits

Running `--strict knowledge research` exposes **74 errors across 21 files / 360 records**, including the 15 knowledge errors. The complete output is saved in `after-strict-all.txt`. These additional research records are outside the brief's warning baseline; do not treat the knowledge-only check as repository-wide clearance. Full-text contract gaps and repeated copied IDs in the research registers need the same owner review.

Default mode retains the legacy standalone `vN` spelling. After review, strict mode requires a pin attached to the paper ID, `ID (vN)`, or an edition-only `vN (date)` field for a single cited paper; arbitrary prose mentioning a tool version is insufficient. Strict online checks query the pinned edition even when the pin is recorded only in the version field. Missing cited-edition title metadata fails strict checking instead of substituting the latest title. Offline mode checks recorded presence/consistency, not existence or actual reading. Online tests use mocked metadata, with network disabled and a temporary cache. Existing title-similarity/prefix heuristics remain; this is not a semantic entailment checker.
