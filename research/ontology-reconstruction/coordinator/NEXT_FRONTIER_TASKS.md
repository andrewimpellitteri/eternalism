# The next ambitious step: organization before temporal inventory

30 October 2026. Prepared task contracts after the response/feedback round.
These are research directions, not novelty claims or launched workers.

## What has changed

The [response benchmark](RESPONSE_MEMORY_BENCHMARK.md) now supplies a
filled transport window, a sharp-support/norm contrast, a source-budget
hierarchy and a nonsingular forced-field experiment with a common energy
upper bound. The [feedback test](FEEDBACK_CONSTITUTIVE_TEST.md) supplies

Bounded analytic review is separate from the prior-result audit. The

by itself earn a temporal ontology.

The strongest question is no longer simply whether physics can select a
duration. It can. It is **which activity makes these carriers one system,
and why should the duration of that activity be its concrete present?**
The failed [constitutive submission](CONSTITUTIVE_SUBMISSION_REVIEW.md)
does not answer this by making every process state-and-law reconstructible.

## 1. Priority: an organizing loop with an independently justified boundary

Prepared task `ontology-coordination-unity`.

Use the finite causal transport/return apparatus already specified. Try a
candidate unity criterion based on reciprocal organization of *physical
carrier parts*, stated before any present extent. A directed dependency
network may distinguish the mutually coordinating loop from a one-way
external drive. This is a lead, not a constitutive theorem: strongly
connected components and feedback modules are familiar mathematical tools.
Primary process/organizational-closure work must be read before adapting
or attributing a criterion.

The exact test is whether interrupting the return link destroys the
proposed unity, merely changes an output, or leaves a simpler unity.
Compare attenuation changes, rerouting with the same delay, external
replacement of the return signal and a physically modeled backreaction
on the source. Specify which laws and boundary conditions are held fixed;
do not use an impossible full-Cauchy-data deletion counterfactual.

Three required adversaries: weak bidirectional couplings might merge
every module; normal-mode coordinates might disguise the physical part
choice; and a realistic source may receive backreaction, defeating the
ideal one-way boundary. Approximate organization may still be real, but
its approximation must be accounted for before any sharp exclusion claim.

Success is a defensible organizational criterion with a concrete
counterfactual contrast and identified limits. It is not “the loop is a
unity because we define feedback as unity”. A negative result identifying
the first independent premise missing is also useful. Only after this
test should a finite coordination cycle be proposed as constitutive.

## 2. Independent positive control: cycle time versus recovery time

Prepared task `ontology-cycle-recovery-test`.

Use the standard Stuart–Landau normal form as an explicit effective
model, not a fundamental relativistic theory:

    z'=(μ+iω)z−β|z|²z,  μ,β>0,  ω≠0.

State a candidate unity criterion based on the attracting nonzero cycle,
independently of which temporal interval should be concrete. Derive its
amplitude, cycle period and transverse recovery rate, then ask which
activity each duration explains. A cycle period and a relaxation time
can both be intrinsic and physically meaningful while doing different
work. Do not infer impossibility of a constitutive selector merely
because there is more than one timescale.

Test a source-faithful process account against the instant-state rival
without repeating the reconstruction fallacy. Account for phase neutrality,
open-system energy supply, effective-model scope and the same-physics
event-realist rival. Read nearest primary process/unity and oscillator
sources before claiming any new result. A linear-stability calculation
is not by itself an ontology or a definition of a self-maintaining body.

Success would identify a physical activity whose duration has a better
claim to constitution than the competing duration, with reasons beyond
predictive sufficiency. If neither wins, state the exact bridge rather
than announce that all constitution is physically untestable.

## 3. Separate technical frontier: whole histories rather than finite samples

Prepared task `lawful-central-history-review`, gated by the existing
integrated finite-control review.

Claude's `claude-central-history/RESULT.md` proposes prescribing an
entire small central scalar history on a finite interval at fixed total
incoming mass. It is an exploratory conditional candidate: its own header
says the first version failed review and labels R3/R4 sketches. This
coordinator round read the claim and limits, not the full inversion proof.
It is not accepted or a new task takeover.

The audit target is derivative loss, finite-cone Volterra inversion,
uniform bounds before the scattering limit, target-dependent compactness,
actual mass normalization and axis regularity for C¹,¹ targets. Continuous
function control must not be inferred from a family of finite-sample
theorems with schedule-dependent thresholds. Smooth-target/smooth-model
upgrade is a further obligation. Same causal past is still weaker than
same whole existing realm.

This technical task can strengthen the available physical comparison;
it cannot substitute for either constitutive test above. No ontology or
novelty verdict follows just from replacing a finite vector by a function.

## Decision rule

Advance a temporal-ontology proposal only if it identifies the real
organization independently, justifies its temporal extent, and explains
what its existential interpretation contributes over the strongest
same-physics rival. Keep the possibility of an emergent process ontology
open without treating a measurement tolerance as a fundamental existence
threshold. These contracts target the missing achievement directly.
