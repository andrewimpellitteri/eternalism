1. Keeping Z=J T_n J Z distinct from Psi=J Z yields Psi=J^2 T_n Psi.
   The residual estimate is direct and consumes no vertex-uniform continuity
   modulus for T_n. The worker objected to a different substitution.
2. Smooth convolution gives smooth finite-cone inputs. A density extension to
   arbitrary unsmoothed Lipschitz trial inputs is unnecessary for this route.
   It remains wrong to infer a smooth limit from this observation.
3. The R3 expansion bounds Lambda-double-prime and I-double-prime using the
   stated source estimates, and closes a=2||y-double-prime||+1 without a
   smallness condition on that target norm. This is a project derivation,
   conditional on named external bounds, not a reconstructed external bootstrap.

   Separating the cubic cut-off tail yields an O(M^2 T_max)+O(M^6) mass bound;
   a window-dependent smallness threshold absorbs the latter. A common late
   compensator avoids support escape while fixing the actual total boundary mass.

   checked worktree or rescue copy. That assertion is not adopted as a completed
