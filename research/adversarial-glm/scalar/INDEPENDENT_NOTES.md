## 1. Reconstruction of the labelled theorem (RESULT.md)

### 1.1 Setup as I reconstruct it

- Parameter `p ∈ ℂ`, `q = 1−p`. For a naturally labelled finite causet `C` on
  `n` labels: `A_p(C) = p^{L(C)} q^{C(n,2) − R(C)}`, `L` = number of cover
  relations, `R` = number of strict comparable pairs. Note `L` and `R` are
  isomorphism invariants, so `|A_p(H)|` is a function of the unlabelled shape.
- Principal = unique greatest element. In a naturally labelled causet the
  greatest element, if present, must carry the largest label (any other element
  has a smaller label and lies below it), so "principal" is equivalent to
  "label n is the unique maximum".
- Doubly principal = `C` and `C` restricted to labels `1..n−1` are both
  principal.
- `R̃_p` = σ-algebra generated by the cylinders `[C] = {histories with prefix
  C}` over doubly-principal `C`. The subscript is Dowker–Zalel's posts-algebra
  label, not a parameter dependence; the generator family is countable, so the
  σ-algebra exists.

**Claim (Theorem 1).** A countably additive, finite-valued complex measure on
`R̃_p` with `μ([C]) = A_p(C)` for every doubly-principal `C` exists **iff**
`p ∈ [0,1]` (real interval).

### 1.2 Step-by-step audit of the two-cap proof

I re-derived each step myself rather than trusting the draft.

**(T1) Two-cap bijection.** If `C` on labels `1..n` is doubly principal, label
`n` is the unique maximum of `C` (T1 above), and label `n−1` is the unique
maximum of `C|_{1..n−1}`. Hence `C = G ⊕ {u} ⊕ {v}` with `u` label `n−1`, `v`
label `n`, `G` an **arbitrary** naturally labelled `(n−2)`-element causet, `⊕`
ordinal sum. Conversely every such ordinal sum is doubly principal. The
correspondence is a bijection. **Verdict: correct.**

**(T2) Amplitude under capping.** With `w(G) = L(G) + M(G)` (`M` = number of
maximal elements) and `h(G) = C(k,2) − R(G)`, `k = |G|`:
- covers of `C_G`: covers of `G`, plus one cover `g ≺ u` for each maximal `g`
  of `G` (elements of `G` are never covered by `v` since `g < u < v`), plus
  `u ≺ v`. So `L(C_G) = L(G) + M(G) + 1 = w(G) + 1`.
- comparable pairs: `R(C_G) = R(G) + 2k + 1`, and `C(k+2,2) = C(k,2) + 2k + 1`,
  so the `q`-exponent is `h(G)`.
Hence `A_p(C_G) = p^{w(G)+1} q^{h(G)}` and `|A_p(C_G)| = a^{w+1} b^{h}` with
`a = |p|`, `b = |1−p|`. **Verdict: correct.**

**(T3) The linear bound `w(G) ≥ k`.** Every non-maximal element has an outgoing
cover; distinct elements have distinct outgoing cover pairs, so
`L(G) ≥ k − M(G)` and `w(G) = L(G) + M(G) ≥ k`. Consequently
`w(G) + h(G) ≥ k` since `h ≥ 0`. **Verdict: correct.**

**(T4) `t = a + b > 1` iff `p ∉ [0,1]`.** Triangle inequality
`t ≥ |p + (1−p)| = 1` with equality iff `p` and `1−p` are nonnegative real
multiples of one number, i.e. `p ∈ [0,1]`. If `p ∉ [0,1]` then also `a, b > 0`
(`p ≠ 0,1`). **Verdict: correct.**

**(T5) Random-graph-order identity.** Claim:
`Σ_G r^{w(G)} s^{h(G)} = F_k(s) = Π_{j=1}^{k} (1 − s^j)` for `r + s = 1`.
My derivation: place independent forward edges with probability `r` on
`0..k` and take transitive closure (Bollobás–Brightwell random graph order).
`P(\text{order} = C) = r^{L(C)} s^{C(n,2) − R(C)}` because cover edges must be
present, incomparable pairs absent, and each redundant comparable pair is free
(factor `r + s = 1`). The event "last vertex above all others" is exactly
`{orders G ⊕ {u}}`, whose probability is `Σ_G r^{w(G)} s^{h(G)}` (using T2 with
one cap instead of two). Reversing order and arrows makes it "first vertex
reaches all others"; exposing vertices in turn, vertex `j` is reached iff at
least one of its `j` incoming edges fires, an event of probability `1 − s^j`
depending only on edges into `j`, hence independent across `j`. Product
`F_k(s)`. **Verdict: correct as an argument; to be re-verified numerically for
`k ≤ 4` (§3).**

**(T6) Positivity of `c_s = Π_{j≥1}(1 − s^j)` for `s ∈ (0,1)`.**
`Σ_j s^j < ∞` and `log(1−x) ≥ −2x` near 0 give a positive infinite product.
**Verdict: correct (standard).**

**(T7) Variation obstruction.** The `[C_G]` at fixed size are pairwise
disjoint (distinct prefixes of equal length) and all lie in `R̃_p` (they are
generators). For any finite-valued countably additive complex measure on a
σ-algebra, total variation is finite (standard theorem: e.g. Rudin, *Real and
Complex Analysis*, Thm 6.4; Folland, *Real Analysis*, Ch. 3 — complex measures
are bounded). Hence `Σ_{|C|=n} |μ([C])| = V_n(p) ≤ ‖μ‖_{TV}` for every `n`.
The lower bound `V_{k+2}(p) ≥ a·t^k·c_s → ∞` (from T2–T6) contradicts this for
`p ∉ [0,1]`. **Verdict: correct.** The uniform bound over `n` is what makes
divergence (not a single `>1` rank) the contradiction; the draft says exactly
this, and its finite certificates are labelled consistency checks only.

**(T8) Sufficiency for `p ∈ [0,1]`.** Classical labelled transitive percolation
(birth process with independent edges, probability `p`) is a probability
measure on the full labelled-history σ-algebra; `P(prefix = C) = A_p(C)` with
the standard convention `0^0 = 1`. Restricting to `R̃_p` gives the measure, at
both deterministic endpoints (`p=0`: antichain history; `p=1`: chain history).
**Verdict: correct.**

**(T9) Larger-algebra corollary.** Every doubly-principal cylinder is a
principal cylinder, so `R̃_p ⊆` (σ-algebra generated by principal cylinders);
a measure on the larger algebra agreeing with `A_p` there would restrict to a
forbidden measure on `R̃_p`. **Verdict: correct.**

### 1.3 My falsifier attempts for Theorem 1 (recorded before any comparison)

1. **Infinite-total-variation escape** (could a countably additive complex
   measure have infinite TV, dodging the bound?). No: finite TV is a theorem
   for countably additive complex measures, not an extra assumption. Attempt
   fails.
2. **Unlabelled-multiplicity mismatch** (maybe the labelled sum overcounts what
   the measure sees?). Irrelevant for Theorem 1: the constraint is per labelled
   cylinder and same-size labelled cylinders are disjoint. Attempt fails.
3. **Two-cap bijection gap** (does some doubly-principal causet fail to be
   `G ⊕ {u} ⊕ {v}`, or is some `G` excluded?). No: natural labelling forces
   the two caps to be the two largest labels; `G` is arbitrary. To be checked
   numerically at `n ≤ 5`. Attempt fails.
4. **Endpoint semantics** (`p=0` gives all-zero prescriptions; is the zero
   measure legal?). Yes: every doubly-principal `C` has `L ≥ 1`, so `A_0 ≡ 0`
   on them and `μ = 0` works; `p = 0 ∈ [0,1]` is consistent. At `p = 1` only
   the chain cylinder gets 1 and the Dirac chain measure works. Attempt fails.
5. **Product identity failure** (T5). To be tested numerically; if `F_k(s)`
   were wrong the bound could collapse. (Numerics in §3 confirm the identity
   at `k ≤ 4`.)
6. **`c_s = 0` for some `s ∈ (0,1)`** — impossible (T6). Attempt fails.
7. **Constructive attempt**: support a measure on a single "thin" tail and hope
   the doubly-principal values vanish. They cannot: the prescription fixes
   `|μ([C_G])| = a^{w+1} b^{h} > 0` on a disjoint divergent family regardless
   of support. Attempt fails.

**Preliminary verdict (correctness), Theorem 1: no counterexample; the proof
reconstructs completely from elementary pieces.** Novelty/prior-art check
pending (§4).

## 2. Reconstruction of the conditional covariant theorem (COVARIANT_RESULT.md)

### 2.1 Setup as I reconstruct it

- `R_p` (Dowker–Zalel posts algebra, parameter-independent): covariant
  (label-invariant) measurable events containing either all or none of
  `P_∞^c`, where `P_∞` = "infinitely many posts".
- For a principal unlabelled `H`, `|H| = n`: `D_H` = histories with infinitely
  many posts and a post whose inclusive past is isomorphic to `H`.
- Assumption (T): one constant `κ ∈ ℂ` with `ν(D_H) = κ·N(H)·A_p(H)` for all
  principal `H`, where `N(H)` = number of natural labellings modulo
  automorphisms.
- Claim: finite countably additive `ν` on `R_p` with `ν(Ω) = ν(P_∞) = 1` and
  (T) exists iff `0 < p ≤ 1`.

### 2.2 Step-by-step audit

**(C1) Posts are totally ordered and past-complete below.** If `x` is a post
and `y` is born before `x` (label smaller), then `y < x`: relations only go
forward in label, so `x < y` is impossible; `x` comparable to `y` gives `y < x`.
Hence a post's inclusive past is exactly `{labels 1..label(x)}`, and a post
with `n−1` ancestors has label `n`. *The draft says "label `n−1`", which is an
off-by-one typo; it does not affect the argument since only measurability is
claimed there.* Two posts are comparable (each is comparable to all elements),
so their inclusive pasts are nested with distinct sizes.

**(C2) Measurability and membership in `R_p`.** `D_H` is label-invariant;
"the label-`n` element has inclusive past `C`" is a cylinder; "every later
element lies above it" is `∩_m {m reachable from n}`, each factor depending
only on the prefix up to `m`; intersecting with `P_∞` gives an event contained
in `P_∞`, hence in `R_p` (its intersection with `P_∞^c` is empty). **Verdict:
correct** (modulo the harmless typo in C1).

**(C3) Laminarity.** For `|H| < |J|`: I claim `D_H ∩ D_J ∈ {∅, D_J}`, and the
witness is: `ω ∈ D_J` contains a post `x_J` with inclusive past `J` (the
maximum of `J`); every post of `ω` with past-size `< |J|` must lie strictly
below `x_J` (posts are totally ordered; a post above `x_J` has past-size
`≥ |J|+1`); the posts of `ω` up to `x_J` are exactly the posts of the finite
causet `J`, with `ω`-pasts equal to `J`-pasts (everything below a member of
`J` is in `J`). Hence `ω ∈ D_H` iff `J` has a post whose inclusive past is
isomorphic to `H` — a condition on `J` alone. For equal sizes, distinct shapes
give disjoint events (nested equal-size pasts coincide, forcing the shapes
equal). **Verdict: correct.** To be sanity-checked on shapes `n ≤ 5` (§3).

**(C4) Covering and `κ ≠ 0`.** The principal `D_H` are countable and cover
`P_∞` (the earliest post of any `ω ∈ P_∞` has a principal finite past). A
laminar family's finite unions are disjoint unions of members, so if all
`ν(D_H) = 0` then all finite unions have value 0, and continuity from below of
the finite complex measure gives `ν(P_∞) = 0 ≠ 1`. **Verdict: correct**, and
the draft is right that laminarity (not a general "null cover" fallacy) is
what licenses this for a complex measure.

**(C5) Necessity for `p ∉ [0,1]`.** Doubly-principal `H` are principal, so (T)
applies; grouping the doubly-principal naturally labelled `n`-orders by shape,
`Σ_{[H] dbl.pr., |H|=n} |ν(D_H)| = |κ| Σ_{[H]} N(H)|A_p(H)| = |κ| V_n(p)`
(shape-invariance of `A_p`), with the `D_H` pairwise disjoint at fixed `n`
(C3). The two-cap bound gives `V_n(p) ≥ |p| (|p|+|1−p|)^{n−2} c_s → ∞`,
contradicting `≤ ‖ν‖`. **Verdict: correct.**

**(C6) `p = 0`.** For principal `|H| ≥ 2`, `L(H) ≥ 1` so `A_0(H) = 0`; the
subfamily `{D_H : |H| ≥ 2}` still covers `P_∞` (a history with ≥ 2 posts has a
post whose past contains an earlier post), stays laminar, so
`ν(P_∞) = 0 ≠ 1`. The `|H| = 1` event (value `κ`) is irrelevant to the cover.
**Verdict: correct.**

**(C7) Sufficiency `0 < p < 1`.** The label-`n` element of a percolation
history is a post of the whole history iff all later vertices are reachable
from it; sequential exposure gives `Π_{j≥1}(1 − q^j) = c(1−p)`, shape- and
`n`-independent. So `P(D_H) = c(1−p) N(H) A_p(H)` (the `P_∞` intersection
removes nothing since `P_∞` is a.s. under percolation — classical result the
draft attributes to Alon et al. via Bombelli–Seggev–Watson; I have not
re-derived it). `κ = c(1−p)`. At `p = 1`: Dirac at the chain, `κ = 1`, (T)
holds since `A_1(H) = 1` only for chains. **Verdict: correct as an argument;
the cited classical facts to be checked against the primary source (§4).**

**(C8) The doubly-principal weakening counterexample.** The history
`⊕_{j≥1} (A_2 ⊕ {z_j})`: each `z_j` is a post; `past(z_j)` deletes to
`… ⊕ A_2` which has two maxima, so no post-past is doubly principal; the
orbit-indicator measure of this one history is a countably additive
probability measure on the covariant algebra (covariant events are unions of
isomorphism orbits, so "intersects the orbit" = "contains the orbit", which
makes finite additivity exact on this algebra) and satisfies the weakened rule
with `κ = 0` for any `p`. **Verdict: correct**, and my independent check that
an orbit-indicator is additive on a covariant algebra closes the one loophole I
suspected ("Dirac at an unlabelled history" would be ill-defined on the
labelled algebra but is fine on the covariant one).

**(C9) Rank-factor attenuation and local renewal.** The bound
`|κ_n| ≤ ‖ν‖ / (|p| c_s (|p|+|1−p|)^{n−2})` follows from C5 verbatim.
For the renewal rule: `J = H ⊕ {x}` with `H` principal has `M(H) = 1` (unique
maximum — this is where principality is used; a naive capping of a
non-principal `G` would give `p^{M(G)}` instead of `p`), so
`A_p(J) = p A_p(H)`, `N(J) = N(H)`, and `D_J ⊆ D_H` (the capped post is a post
of any history in `D_J`, with past `H`). Classical ratio is `p`. Applying the
axiom to the chain forces `κ_{n+1} = κ_n`. **Verdict: correct.**

**(C10) Analytic corollary.** If a holomorphic-in-`p` family on a connected
`U ⊂ {|1−p| < 1}` meets the real interval and agrees with percolation there,
the identity theorem forces `ν(D_H) = c(1−p) N(H) A_p(H)` throughout `U`,
which (C5) cannot come from a finite measure off the real interval.
**Verdict: correct, scope honestly restricted in the draft.**

### 2.3 My falsifier attempts for the conditional theorem

1. **`κ = 0` escape via a measure supported on posts but not on any single
   `D_H`.** Killed by C4: the principal `D_H` cover `P_∞` laminarly. I tried
   to break the cover by finding an `ω ∈ P_∞` whose post-pasts are all
   non-principal — impossible, every post's past has the post as maximum.
   Attempt fails; the draft's own doubly-principal counterexample shows the
   escape *does* work for the weakened rule, which is the honest boundary.
2. **Disjointness gap at fixed rank** (two shapes sharing a history). Killed
   by C1/C3 (nested pasts of posts). Attempt fails.
3. **`D_H ∉ R_p`** (event not covariant or not in the posts algebra). Killed
   by C2 (intersection with `P_∞` empties `P_∞^c`-overlap). Attempt fails.
4. **`N(H)` bookkeeping error** making `|κ| V_n` wrong. The grouping identity
   is exact because `A_p` is shape-invariant. Attempt fails.
5. **Sufficiency gap: (T) secretly fails for real percolation** because
   `{n is a post}` does not imply `P_∞`. Killed: `P(P_∞) = 1` a.s. removes the
   difference; `κ = c(1−p)` survives. The dependency on the a.s.-infinitude of
   posts is a real (cited, classical) input — flagged for primary-source check.
6. **p = 0 measure with `ν(P_∞) = 1` concentrated on `D_{|H|=1}`-like events.**
   Killed by C6: the `|H| ≥ 2` family alone covers `P_∞`. Attempt fails.
7. **Renewal-rule attack**: I initially suspected `A_p(H ⊕ {x}) = p A_p(H)` is
   false because capping adds `M(H)` covers. It is false in general but `H` is
   principal, so `M(H) = 1`. The draft survives this attack; the subtlety is
   worth stating in the final report since it is exactly where a weaker
   (non-principal) version of the rule would break.

**Preliminary verdict (correctness), Theorem 2: no counterexample under the
stated assumption set; the classification is conditional in exactly the way
the draft says (a covariant measure with different post amplitudes is outside
the statement, as the draft's own Dirac example shows).** Novelty/prior-art
check pending (§4).
