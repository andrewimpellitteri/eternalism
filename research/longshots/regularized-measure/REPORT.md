## Verdict: KILLED, with one obstruction on each side of |1−p| = 1

1. **Region I, `p ∉ [0,1]`, `|1−p| < 1`** (test values p = 3/2, (1+i)/2).
   No regularization is needed: every event in the stem algebra 𝒜 has a
   convergent stage sequence (Lemma 1). The limits are finitely additive on 𝒜,
   countably additive on each fixed k-skeleton σ-algebra, analytic in p on the
   disk, and equal to the honest measure for real p ∈ (0,1]. **Obstruction
   (Theorem 2):** the limits have infinite total variation on 𝒜, so no countably
   additive complex measure on σ(𝒜) agrees with them. Every regular summation
   method returns the same limits, so regularization cannot change this. The
   labelled-cylinder series is not absolutely convergent and depends on grouping.
2. **Region II, `|1−p| > 1`** (test value p = −1/2). Every nontrivial stem
   sequence diverges like `|q|^{n²/2}` (proved for the 2- and 3-antichain stems,
   observed for the other five to n = 70). Cesàro (C,1)/(C,2), Abel, Borel, Euler
   (E,1) and every finite-order Gevrey method fail. Base-q q-Borel–Laplace gives
   direction-independent finite values **only on the antichain sector** (2- and
   3-antichain stems → 1; `#min = j` → 0 for j ≤ 5); other stems have q-Borel
   transforms of radius 0. Nothing ties these values to real p.
3. **Boundary `|1−p| = 1`**: one sample, p = (2−4i)/5; every nontrivial sequence
   fails to converge, including under Cesàro and Euler means, to N = 60.

**Conjecture C1** (falsifiable): (a) for `|1−p| > 1`, every stem other than the
1-element stem has `log|a_n| = (log|q|/2) n² + o(n²)`; (b) base-q q-Borel–Laplace
assigns 1 to every k-antichain stem and 0 to every `#min = j`, i.e. the Dirac
measure at the infinite antichain (the honest p = 0 measure). Evidence: (a) at
p = −1/2, n ≤ 70; (b) k = 2, 3 and j ≤ 5 only.

Maximum stages: labelled enumeration n = 9 (116,473,461 naturally labelled

## Definitions

`q = 1−p`; `A_p(C) = p^{L(C)} q^{binom(n,2)−R(C)}` (L covering relations, R
relations); stage sums are 1 as a polynomial identity (checked exactly, n ≤ 9).
New element with past down-set D: amplitude `p^{|max D|} q^{m−|D|}`. Stem
amplitude `a_n(S) = Σ{A_p(C): |C| = n, some down-set of C ≅ S}` for all 8 posets
of size ≤ 3 (1, 2chain, 2anti, 3chain, 3anti, V, Lambda, 2chain+1). 𝒜 = algebra
generated by stem events. k-skeleton `K_k(C) = {x : |past(x)| ≤ k−1}`. Post event
`D'_H = {K_n ≅ H}` for principal H, |H| = n.

## Lemmas and theorem

- **Lemma 1 (k-skeleton chain).** Whether a k-element S is a stem depends only on
  `K_k(C)`, itself a down-set; the labelled skeleton process is an exact marginal
  Markov chain (an element joins iff `|D| ≤ k−1`; all other moves have total
  amplitude `1 − Σ_small` and leave K unchanged). With
  `s_m ≤ (m+1)^{k−1} max(1,|p|)^{k−1} |q|^{m−k+1}`, trajectory variation
  `T_n ≤ Π(1+2s_m) < ∞` for `|q| < 1`, so increments are summable, every
  `a_n(E)` converges locally uniformly, the limit is analytic, and the trajectory
  measure is countably additive on each skeleton σ-algebra. Checks: chain and
  enumeration polynomials agree for all 8 stems to n = 9; `|Δ_{n+1}/Δ_n| → |q|`.
- **Lemma 2.** `K_k ≅ P` iff P is a stem and no k-small poset of size |P|+1 is a
  stem (20,924 cases, |C| ≤ 6, k ≤ 4, 0 failures). Hence `D'_H ∈ 𝒜`, with stage-N
  amplitude `N(H) A_p(H) (q;q)_{N−n}` (116 cases, 0 mismatches), so
  `μ(D'_H) = N(H) A_p(H) (q;q)_∞`: the common-factor rule (T) of
  `research/creative/COVARIANT_RESULT.md` holds with `κ = (q;q)_∞`, derived, not
  assumed.
- **Theorem 2.** For `p ∉ [0,1]`, `|1−p| < 1`: the disjoint rank-n events `D'_H`
  give total variation `≥ |(q;q)_∞| P_n(p)`, `P_n = Σ_principal N(H)|A_p(H)|
  ≥ V_n ≥ |p| t^{n−2} c_s → ∞` (`RESULT.md`), and `(q;q)_∞ ≠ 0`. So μ has infinite
  variation on 𝒜 and no countably additive extension to σ(𝒜). Not excluded: a
  countably additive measure on σ(𝒜) with values on 𝒜 different from the stage
  limits.

## Label-independence and additivity

- Grouping (n ≤ 9): stage-grouped `|μ(E_m)|` decays geometrically, but the same
  events split into labelled cylinders have `W_m = Σ|A_p(C)|` growing (p = 3/2,
  2chain, m = 5..9: 1.67, 3.66, 9.58, 29.1, 100). The labelled series is not
  absolutely convergent; by Lévy–Steinitz its rearrangement sums form at least a
  line. At p = 1/2, `W_m = |μ(E_m)|` exactly.
- Finite additivity: `[2chain ∧ 2anti] = [2chain+1]` and `[2chain ∨ 2anti] = Ω`
  for n ≥ 2 on all 119,375,592 labelled causets (n ≤ 9), so
  `a(2chain) + a(2anti) − a(2chain+1) = 1` exactly at every p. At p = −1/2 the
  parts diverge while the union is identically 1.
- Countable additivity within the 1-skeleton: `Σ_j μ(#min = j) = 1` to 1e-12 at
  three p, finite variation (1.441, 4.386, 1).
- Real-p control: Monte Carlo percolation at p = 1/2, 20,000 samples of 40
  elements, seed 20261021; all 8 stems agree with exact `a_40` (|z| ≤ 1.01).
