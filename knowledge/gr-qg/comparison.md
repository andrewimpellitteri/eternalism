# Global spacetime structure and canonical time: comparison contract

Checked 2026-10-19. This is a bounded source map, not a systematic review. “Global time” below means a mathematical time function when explicitly stated. It does not by itself mean clock time, a unique preferred foliation, objective passage, or eternalism. Source IDs point to the task register unless an existing knowledge-base ID is given.

## Shared contrasts

Global hyperbolicity is a causal-structure condition. In the Bernal–Sánchez results it is a sufficient condition for the existence of a smooth Cauchy temporal function and splitting, not a selection principle for a unique slicing. Cosmological time is a metric-defined candidate only when its regularity condition holds. Gödel’s exact solution shows that local time orientation and a global time function can come apart. Canonical “frozen time” is a feature of a constrained formalism and its quantization strategy; it is not evidence that physical change is absent. The spin-glass paper studies algebraic evidence for a possible emergent bulk causal structure using an already time-dependent boundary system; it does not derive physical time or a global foliation.

## What would defeat a stronger claim

- A claim that relativity always supplies a global time is already defeated by Gödel’s exact solution unless the claim adds a causal restriction such as global hyperbolicity. If it adds global hyperbolicity, the Bernal–Sánchez theorem supplies existence, but still not a unique or privileged slicing.
- A claim that a natural cosmological time is generally available must state and defend the regularity premise. The theorem cannot be generalized to arbitrary spacetimes by dropping it; Minkowski already fails its finiteness requirement.
- A claim that canonical quantum gravity has no time because the Wheeler–DeWitt equation is frozen must compare internal clocks, relational observables, histories, and semiclassical constructions. Isham and Anderson describe a family of problems and strategies, not a universal impossibility result.
- A claim that the 2510.20902 proposal derives time or spacetime must point to more than boundary-time input and spectral diagnostics. Its current inspected results are algebraic/numerical indicators under large-N assumptions; full proof, code, and finite-N correspondence audits would be needed for stronger claims.
- Any bridge from these mathematical or formal results to eternalism, presentism, growing block, or objective passage needs an explicit independent philosophical premise. None of these source results alone decides those positions, determinism, or the thermodynamic arrow.
