The strongest remaining scientific bottleneck is a precise, empirically
articulated bridge from causal/metric/dynamical structure to ontological

observable that discriminates the disputed ontologies.

## Critical sanity check update

The isolated theorem statement transcribed from the Stein 1991 web OCR is
formally false as written: universal `R` satisfies its listed properties,
and so does reflexive chronological past, which omits null past points. The
surrounding proof context contains the missing constraints—condition (iv)
(unsettled points remain) and inclusion of the entire causal past. The
web-accessible source did not expose a page image, so whether this is a print
omission, OCR/transcription loss, or contextual excerpting cannot be settled.
`audit.md` now distinguishes the displayed wording from the context-preserving
reconstruction and prohibits attributing an error to Stein without a scan
check. Any formalization must encode the full contextual assumptions and test
these elementary countermodels first.
