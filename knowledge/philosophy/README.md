# Added philosophical source register

Companion to [the dense map](../PHILOSOPHY_OF_TIME.md). Every record in
`sources.jsonl` states how little or how much was actually inspected. A book's
abstract does not count as a deeply read anchor. This register contains new
records, not necessarily new unique works relative to the seed and lane files.

|---|---|---|
