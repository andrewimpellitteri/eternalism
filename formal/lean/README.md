# Light Lean kernel

This is the **lightweight** Lean part of the certificate. It is a single
self-contained file, checked by `lean` directly. There is **no Lake project, no
mathlib, and no dependency download**.

## Toolchain

- Lean 4.35.0, commit `eb6cafb7290e8bd5f2937522d8d804f58f02bafc` (Release),
  arm64-apple-darwin.
- Installed with `elan`; no libraries beyond the core toolchain.
- Build command: `lean formal/lean/Certificate.lean`.
- The file imports nothing.

## What it checks

`Certificate.lean` defines naturally labelled causets on `{0,…,n-1}` as
transitive Boolean relations in a bitmask, plus principal/doubly-principal
predicates, the two-cap map `G ↦ G ⊕ {u} ⊕ {v}`, covers, incomparable pairs,
and finite amplitude sums. It then proves by finite evaluation (`decide`):

| Theorem | Statement |
|---|---|
| `causet_count_four` | there are `40` naturally labelled causets on four elements (the counts for `n=1,2,3` are also checked) |
| `two_cap_five` | the doubly-principal five-element causets are exactly the two-caps of the three-element causets (and the analogous statements for sizes 3 and 4) |
| `covers_three` | capping adds `M(G)+1` covers for every three-element `G` (also checked for sizes 1 and 2) |
| `incomparable_*` | capping adds no incomparable pairs |
| `amp_factor_two` | for the integer instance `p=2, q=3`, `V_4 = p · Σ_G p^{L(G)+M(G)} q^{h(G)}` |

`#print axioms` reports for each named theorem:

```
'Cert.causet_count_four' does not depend on any axioms
'Cert.two_cap_five' does not depend on any axioms
'Cert.covers_three' does not depend on any axioms
'Cert.amp_factor_two' does not depend on any axioms
```

There is no `sorry`, no `axiom` declaration, and no admitted goal.

## What it does not check

- The all-level analytic divergence and the measure-theoretic contradiction.
- The sigma-algebra generated by the cylinders, countable additivity, complex
  measures, total variation, or the Euler product.
- The conditional covariant post-factor theorem.
- Any physical or ontological interpretation.

`formal/INFEASIBILITY.md` records the full-formalization route and why it is
deferred (mathlib measure theory plus a causal-set layer would be a multi-week
project, and the user asked to keep dependencies light).

## Reproduce

```sh
source "$HOME/.elan/env"      # or have lean on PATH
lean formal/lean/Certificate.lean
```

The command prints the four `#print axioms` lines and exits zero. The top-level
`formal/check_certificate.sh` also runs this file when `lean` is available.

## Scope note

This kernel is a finite verification of proof steps 1–3 of
`research/creative/RESULT.md` (decomposition, cover/incomparable counts, and the
amplitude factorization at a concrete instance). It is not the theorem, not a
novelty certificate, and not an ontology result.
